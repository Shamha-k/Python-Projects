Exploratory Data Analysis and Prediction of Titanic Survival

Developed an end-to-end data analysis and machine learning pipeline to predict passenger survival using the Titanic dataset.
The project focused on extracting meaningful insights through exploratory data analysis (EDA) and building multiple classification models to evaluate predictive performance.

Performed comprehensive data preprocessing using pandas and NumPy, including handling missing values, feature encoding (one-hot encoding), and data transformation.
Conducted detailed EDA with Matplotlib and Seaborn to uncover patterns related to survival based on features such as gender, passenger class, and age.

Implemented and compared multiple classification algorithms using scikit-learn, including Logistic Regression, Decision Tree, Random Forest, K-Nearest Neighbors, Support Vector Machine, and Naive Bayes.
Evaluated models using key metrics such as Accuracy, Precision, Recall, F1-score, and ROC-AUC, and visualized performance using ROC curves.

Achieved optimal performance with Support Vector Machine (highest F1-score and accuracy), while Logistic Regression demonstrated strong generalization with the highest ROC-AUC score.
The project highlights strong foundations in data analysis, feature engineering, model evaluation, and comparative machine learning techniques.
